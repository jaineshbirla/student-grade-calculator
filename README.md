# Student Grade Calculator 🎓

A simple, interactive Python program to calculate student grades, average percentages, and performance evaluations.

## Features
- Dynamic input for any number of subjects.
- Input validation to handle non-numeric inputs and out-of-bound marks.
- Automatic grade calculation (A, B, C, D, F) with personalized feedback.
- Clean formatted terminal summary.

## How to Run
1. Ensure Python 3.x is installed.
2. Run the program in your terminal:
   ```bash
   python student_grade_calculator.py
